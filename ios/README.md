# Читалка для iPhone та iPad (iOS)

iOS-версія Android-додатку «Читалка»: ті самі можливості, написано на Swift (SwiftUI + UIKit), iOS 15 і новіше.

## Що вміє

- **PDF** – усі сторінки, вертикальне гортання, масштаб щипком або подвійним дотиком, перехід до сторінки.
- **DOCX** – текст із жирним/курсивом/підкресленням, заголовки, списки, таблиці (рядок таблиці – один рядок тексту), вбудовані картинки.
- **DOC** (Word 97–2003) – текст і таблиці (без форматування).
- **RTF** – текст із форматуванням (часто такі файли мають розширення .doc).
- **JPG / PNG / HEIC** та інші фото – можна вибрати кілька фото з галереї одразу, вони відкриються як сторінки одного документа.
- **Колір сторінки** (кнопка з палітрою): звичайна, нічна, сепія, сутінки, контрастна, м'яка зелена, синя.
  Для PDF і фото тема застосовується перефарбуванням: світле стає кольором сторінки, темне – кольором тексту.
  Для фото перефарбування можна вимкнути в меню «…».
- **Редагування документів Word**: меню «…» → «Редагувати», виділіть текст і натисніть Ж / К / П.
  «Зберегти» створює новий файл DOCX (картинки в ньому не зберігаються).
- **Зберегти як PDF**, **Поділитися**, **Поділитися як PDF**, **Друк** (AirPrint або «Зберегти в Файли» як PDF).
- Запам'ятовує останній документ, місце, де ви зупинились, і масштаб.
- Відкривається з «Файлів», пошти, месенджерів («Поділитися» → «Читалка» або «Відкрити в…»).

## Як встановити на iPhone

Apple дозволяє встановлювати застосунки не з App Store лише підписаними. GitHub Actions збирає
**непідписаний** файл `DocReader-N.ipa`; підписати його можна безкоштовно своїм Apple ID:

1. На вкладці **Releases** репозиторію знайдіть «Читалка для iPhone, збірка N» і завантажте `DocReader-N.ipa`
   на комп'ютер (Windows або Mac).
2. Встановіть [Sideloadly](https://sideloadly.io) (або AltStore), підключіть iPhone кабелем.
3. Перетягніть `.ipa` у Sideloadly, введіть свій Apple ID і натисніть **Start**.
4. На iPhone: **Параметри → Загальні → VPN і керування пристроєм** → довірити свій Apple ID.
   На iOS 16+ також увімкніть **Параметри → Приватність і безпека → Режим розробника**.

З безкоштовним Apple ID підпис діє 7 днів – потім застосунок треба переустановити (AltStore робить це
автоматично). З платним обліковим записом розробника Apple ($99/рік) підпис діє рік, і можна роздавати
застосунок через TestFlight.

## Збірка на Mac

Потрібні Xcode 15+ і [XcodeGen](https://github.com/yonaskolb/XcodeGen):

```bash
cd ios
brew install xcodegen
xcodegen generate
open DocReader.xcodeproj
```

У Xcode виберіть свою команду (Signing & Capabilities), підключіть iPhone і натисніть Run.
