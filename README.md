# Читалка (DocReader)

Android-додаток для читання багатосторінкових документів і зображень з вибором кольору сторінки.

## Що вміє

- **PDF** – усі сторінки, гортання, масштабування щипком або подвійним дотиком, перехід до сторінки.
- **DOCX** (Word 2007+) – текст із жирним/курсивом/підкресленням, заголовки, списки, таблиці (рядок таблиці – один рядок тексту), вбудовані картинки.
- **DOC** (Word 97–2003) – текст і таблиці (без форматування).
- **RTF** – текст (часто такі файли мають розширення .doc).
- **JPG / PNG** (а також WEBP, BMP, GIF) – можна вибрати кілька фото одразу, вони відкриються як сторінки одного документа. Враховується поворот з EXIF.
- **Колір сторінки** (кнопка з палітрою):
  - звичайна – чорний текст на білому;
  - нічна – білий текст на чорному;
  - сепія, сутінки (сірий), контрастна (жовтий на чорному), м'яка зелена, синя.

  Для PDF і фото тема застосовується перефарбуванням: світле стає кольором сторінки, темне – кольором тексту. Для фото перефарбування можна вимкнути в меню.
- Запам'ятовує останній документ, місце, де ви зупинились, і масштаб.
- Відкривається з файлового менеджера, пошти, месенджерів («Відкрити за допомогою…» / «Поділитися»).

## Як встановити

1. Відкрийте вкладку **Releases** репозиторію (або **Actions → останній запуск → Artifacts**).
2. Завантажте `DocReader-N.apk` на телефон і відкрийте його.
3. Якщо Android попросить – дозвольте встановлення з цього джерела.

Нові версії встановлюються поверх старих (APK підписано одним і тим самим ключем `app/reader.keystore`).

## Збірка локально

Потрібні JDK 17 і Android SDK:

```bash
./gradlew assembleRelease
# APK: app/build/outputs/apk/release/app-release.apk
```

Вимоги: Android 8.0 (API 26) і новіше.
